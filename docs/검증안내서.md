# 검증 안내서

각 항목은 3단계 이내, 30초 내에 확인 가능해야 한다. 자동 검증 증거는 `docs/검증스크린샷/README.md`에서 찾는다.

1. **상태·투명성 확인**: `/verification` 접속 → 카드 5개와 정상/오래됨/점검/호출 제한/조회 실패 배지, 출처·원천/조회 시각 확인
2. **실시간 API 확인**: `/` 접속 → Upbit·GitHub 실제 값 확인; 키 등록 후 Lost Ark·환율도 조회 실패가 아닌 실제 값인지 확인
3. **키 노출 확인**: 개발자도구 Network → 브라우저 요청이 `/api/widgets/*`뿐이며 URL·응답·화면에 Authorization/serviceKey 실제 값이 없는지 확인

## 자동 검증
1. `npm run build`
2. `npm run test:e2e`
3. 새 `docs/검증스크린샷/<실행시각>/` 폴더와 `5 passed` 확인

E2E는 데스크톱 상태 fixture, 실제 대시보드, 공개 API 계약·키 비노출, 모바일 수동 새로고침 쿨다운, 다크 모드를 검사한다. 오류 시 마지막 성공값 보존과 429/503 분기는 Vitest 단위 테스트가 검증한다.
