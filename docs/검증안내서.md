# T04 검증 안내서

## 어디로 가나요

- 공개 대시보드: 배포 승인 후 생성되는 `realtime-info-board-t04` 공개 주소
- 장애 검증: 같은 주소의 `/verification`

현재 기존 주소 `https://realtime-info-board.vercel.app/`는 원본 프로젝트 배포본이다. 복사본 변경을 배포하기 전에는 T04 신규 기능의 공개 증거로 사용하지 않는다.

## 무엇을 하나요

1. `/`에서 비트코인 현재값·단위·출처·조회 시각과 `하루 한 번 기록`의 실제 날짜 2건을 확인하고 출처를 한 번 누른다.
2. 같은 화면에서 이전·현재 값과 변화 방향·차이·단위를 확인한 뒤 `일별 기록 동기화`를 두 번 눌러도 날짜별 행이 늘지 않는지 본다.
3. `/verification`에서 장애 5종을 차례로 누르고 `오래된 데이터`·빈 상태·`다시 시도` 복구를 확인한다.

## 무엇이 보이면 통과인가요

- 값·KRW 단위·Upbit 출처·조회 시각이 한 화면에 있고 출처 링크가 원자료를 연다.
- Asia/Seoul 기준 서로 다른 실제 날짜 2행만 보이고, 이전 대비 증가/감소/변화 없음과 차이·KRW가 보인다.
- timeout·인증 실패·호출 제한·오프라인·응답 형식 변경이 서로 다른 문구로 보이며 마지막 정상값은 `오래된 데이터`, 정상값이 없으면 빈 상태가 된다.

## 안 될 때

- 값이 다르면 원자료의 `trade_price`, `candle_date_time_kst`, KRW 단위와 화면 행을 대조한다.
- 날짜가 중복되면 localStorage `pulseboard-daily-records-v1`의 `id=upbit:KRW-BTC:날짜`와 Asia/Seoul 변환을 확인한다.
- 장애가 구분되지 않으면 `/verification`의 선택 버튼, `장애 유형`, `다시 시도`를 확인한다.
- 공개 주소에 신규 영역이 없으면 아직 복사본이 배포되지 않은 상태이므로 배포 승인·완료 여부를 먼저 확인한다.
