# 포트폴리오 소개글

**Daylog** — 내 위치의 날씨와 비트코인·환율·공휴일을 한눈에 보고, 하루 한 번 날짜별로 자동 기록해 변화를 보여 주는 개인용 정보판입니다. (<https://realtime-info-board-t04.vercel.app/>)

외부 API는 언제든 실패한다는 전제로 설계했습니다. 모든 카드는 값과 함께 출처·원천 시각·조회 시각을 보여 주고, 장애가 나면 원인을 구분해 안내하며 마지막 정상값을 '오래된 데이터'로 남깁니다. API 키는 Next.js Route Handler에만 두고, 키가 없어도 기본 화면이 오류 없이 동작하도록 대체 공급자와 "연결하면 더 보여요" 안내를 넣었습니다.

기기 위치의 날씨에 맞춰 낮·밤·구름·비·눈·안개·뇌우 장면이 바뀌는 첫 화면, 8월 1일부터의 과거값 자동 채움과 한국 시간 기준 하루 한 건 기록, 개요·달력·추세 시각화를 구현했습니다. 3D 시각화는 한눈에 읽기 어려워 평면 차트로 바꾼 판단 과정도 README에 남겼습니다.

품질은 수치로 확인했습니다: Lighthouse(모바일, 프로덕션 빌드) 성능 98·접근성 100·모범 사례 100·SEO 100, axe-core 위반 0건, 단위 테스트 108개와 Playwright E2E 24개. 기록 백필의 O(n²) 병목을 찾아 총 차단 시간을 2,130ms에서 140ms로 줄였습니다. AI 코딩 에이전트와 협업했고, 범위와 디자인 판단은 직접 내렸습니다.
