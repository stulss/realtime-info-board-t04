# 포트폴리오 소개글

개인 관심사(게임 시세·공지, 암호화폐, 환율, 서비스 상태)를 한 화면에서 투명하게 확인할 수 있는 실시간 대시보드를 설계·구현했습니다. 모든 위젯이 값뿐 아니라 출처, 원천 시각, 조회 시각을 함께 표시하도록 공통 데이터 계약(`WidgetData<T>`)을 설계해 신뢰할 수 있는 정보 제공을 목표로 했습니다.

Next.js Route Handler로 비밀 키를 서버에 격리하고, 공급자별 adapter를 공통 timeout/retry·429/503 분기 계층에 연결했습니다. 위젯별 TTL 캐시, 동시 요청 dedupe, 실패 시 마지막 성공값 보존을 적용해 외부 API 장애에도 정보판이 비지 않도록 했습니다. Vitest 단위 테스트 12개와 Playwright production E2E 5개, 반응형·다크 모드 스크린샷으로 동작과 보안 경계를 검증했습니다.
