# T04 최종 로컬 검증 결과

- 실행 시각: 2026-08-27 14:19 KST
- production build 통과, Playwright E2E 9/9 통과
- 실행 ID 폴더는 매번 새로 만들고 기존 폴더 재사용은 시작 단계에서 거부

카드 1·2·3·5는 로컬 판정 통과했다. 카드 4는 완료된 실제 Upbit 일봉 2026-08-25·26 두 건과 날짜 중복 방지까지 통과했지만, 서로 다른 실제 날짜에 앱을 직접 실행한 두 번째 저장은 시간 경과 후 추가 확인이 필요하다.

원자료·저장값·계산 입력값·화면값은 각각 독립 열로 대조된다. 2026-08-25 109,165,000 KRW에서 2026-08-26 109,830,000 KRW로 +665,000 KRW, +0.61% 증가하며 손계산과 화면이 일치한다. 저장값을 1 KRW로 조작하면 비교가 중단되고 경고가 표시된다.

장애 실험실은 실제 `/api/verification/failure?kind=` 요청으로 timeout·401·429·연결 끊김·응답 형식 변경을 재현하고 정상값 보존, 빈 상태, 검증 API 복구를 확인했다. 소스·client build·Git 전체 기록의 고신뢰 자격증명 패턴은 0건이며 `.env.local`은 존재하지 않았다.

공개 배포는 별도 승인 전이므로 공개 주소 완료 기준은 대기 상태다.
