발견한 문제 3가지:
1. 401과 429가 화면에서 구분되지 않는다 (스크린샷 해시 일치).
2. 오프라인과 timeout이 화면에서 구분되지 않는다 (스크린샷 해시 일치).
3. 응답 형식이 바뀌면 `pageerror: Cannot read properties of undefined (reading 'docsUrl')`로 **정보판 전체가 죽는다.** 에러 경계가 없어 다시 시도 버튼조차 사라진다.

또한 어떤 장애에서도 "마지막 정상값 + 오래된 데이터" 표시가 나타나지 않고 모두 `표시할 데이터 없음`으로 떨어졌다. `/verification` 페이지의 5종 배지는 **fixture(가짜 데이터)** 이며 실제 장애 재현 결과가 아니다.

## 카드 4·5 상세

- 날짜별 저장이 전혀 없다. localStorage에는 테마 키 하나뿐이고, 화면에 `날짜별`·`기록`·`기준 시간대` 문구가 0건이다.
- `Asia/Seoul`은 `src/lib/providers/exim.ts:24`에서 환율 조회일 계산에만 쓰이며, 기록 기준 시간대 명시가 아니다.
- 카드 5의 `전일 평균 대비 -11.8%`, `24시간 -0.70%`는 공급자 응답 필드(`YDayAvgPrice`, Upbit 변동률)를 그대로 보여준 값이다. 프로젝트가 직접 저장한 두 날짜 기록을 비교한 값이 아니므로 카드 5의 "원자료·저장값·계산값·화면값 대조" 요구를 충족하지 못한다.
- 차이가 %로만 나오고 절대 차이(골드·원)와 방향 문구가 없다.
