# 00 요구사항 매핑

> 이 프로젝트는 학교 과제가 아니라 사용자가 직접 작성한 전략 문서 기반 개인 프로젝트다. law.md의 "과제 체크리스트" 개념을 사용자 제공 전략 문서(`personal-realtime-dashboard-strategy-complete.md`)의 요구사항으로 대체해 매핑한다.

## 필수 항목 (전략 문서 0장·4장·7장 기준)
| 요구사항 | 출처(원본 문서) | 상태 |
|---|---|---|
| 모든 위젯에 값 + 출처 + 원천 시각 + 조회 시각 표시 | 0장 | 구현·fixture/E2E 검증 완료 |
| 서버에서만 외부 API 키 사용 (`NEXT_PUBLIC_` 금지) | 4.4장 | Route Handler·server adapter 구현, 정적 보안 검사 완료 |
| 429/503/네트워크 오류 구분 처리 | 1.2장 | 공통 HTTP 오류와 상태 배지 구현·단위 테스트 완료 |
| 실패 시 마지막 성공값 유지 | 4.3장 | TTL cache stale fallback 구현·단위 테스트 완료 |
| 로스트아크 "점검 공지"와 "OpenAPI 접근 불가" 분리 표시 | 1.4장 | 공지 문구와 503 상태를 별도 구현·fixture 검증 완료 |
| 출시 전 체크리스트(7장) 전체 통과 | 7장 | 로컬 항목 통과, 실제 키 기반 배포 검증 대기 |

## 사용자 자체 확인 항목
| 항목 | 확인 시점 |
|---|---|
| 위젯 5개 최종 목록 승인 | 작업지시서 구현 요청으로 확정 |
| 로스트아크 API 키 발급 여부 | 미확인 — 배포 전 사용자 등록 필요 |
| 상업적 이용 여부 (개인용으로 한정) | 개인용 전제로 구현, 배포 전 사용자 재확인 |

사용자가 직접 수행할 전체 절차와 비밀값 보호 기준은 `사용자_사전작업_체크리스트.md`를 따른다.
