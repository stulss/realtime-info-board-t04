## 공개 asset 확인

새 체크리스트가 요구하는 `assets/studio-task-assets/t04-real-information-board/README.md`, `public-contract.json`, `asset-manifest.json`은 이 워크스페이스에서 발견되지 않아 SHA-256 검증을 수행할 수 없다. 제공되면 해시 대조를 추가한다. 현재 장애 검증은 프로젝트 합성 API만 사용했다.

공개 배포 URL은 확보했다. 합성 D1/D2 또는 기존 원천 두 일봉을 C21/C22의 서로 다른 앱 실행 날짜로 주장하지 않는다. 실제 다음 날짜 실행·외부 asset 패키지는 증거를 조작하지 않고 `[~]`로 남겼다.
