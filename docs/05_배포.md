# 05 배포

## 배포처
Vercel (Hobby 플랜)

**현재 상태:** `https://realtime-info-board-t04.vercel.app/` 운영 중(2026-11-04 확인). 포트폴리오 개편(Daylog)이 `main` 푸시로 자동 배포된다.

사용자가 직접 준비할 계정·키·승인 범위는 먼저 `사용자_사전작업_체크리스트.md`에서 확인한다.

> **환율 API migration 완료 (2026-08-26):** 요청 주소를 `oapi.koreaexim.go.kr`로 변경했고, `RESULT 2/3/4`, 비영업일·11시 전 빈 응답, 1,000회/일 제한을 반영했다. 1시간 서버 캐시로 최대 24회/일만 공급자를 조회한다.

## 선택 근거
- Next.js Route Handler와 결합이 가장 단순하다 (원본 전략 문서 4.5장)
- 무료 티어로 개인 저트래픽 대시보드 운영이 가능하다

## 절차
1. Vercel Dashboard에서 `https://github.com/stulss/realtime-info-board-t04` 저장소 Import
2. Framework Preset이 Next.js인지 확인
3. Production 환경변수(모두 선택): `EXIM_SERVICE_KEY`(한국 고시환율), `DATA_GO_KR_SERVICE_KEY`(기상청·에어코리아 — 공공데이터포털에서 두 API를 각각 활용신청). `NEXT_PUBLIC_` 접두사 금지. 키가 없어도 날씨·대기질·비트코인·공휴일·환율(참조환율)은 동작하고, 키가 필요한 카드는 "연결하면 더 보여요" 안내로 대체된다. `LOSTARK_API_KEY`는 더 이상 쓰지 않는다.
4. 환경변수를 추가·변경했다면 새 배포 또는 Redeploy
5. 생성된 공개 배포 주소를 다음 검증 작업자에게 전달
6. 배포 후 브라우저 Network 탭에서 키 노출 여부와 실데이터(콘솔 오류 0건) 검사
7. Vercel Functions 사용량 한도를 배포 직전 공식 문서에서 재확인

## 배포 전 로컬 확인
1. `npm install && npm run lint && npm run typecheck && npm test`
2. `npm run build`
3. `npm run build` 후 `npm run test:e2e` — production 서버 E2E 24개와 새 스크린샷 세트 생성(빌드를 먼저 해야 최신 화면이 검증된다)

`.env.local`은 `.gitignore`에 포함되어 있으며 실제 키를 문서·스크린샷·로그에 남기지 않는다.

## 대안 검토
GitHub Pages + Cloudflare Worker 프록시도 가능하나, Next.js 단일 스택보다 구성 요소가 늘어나 채택하지 않았다.

## 상업 운영 시 주의
Open-Meteo 무료 API는 비상업적 이용 한정이다. 포트폴리오 시연에는 문제없지만, 상업 서비스로 운영하려면 상업용 구독 또는 대체 공급자가 필요하다(`/about`에도 명시).
