# 01 기획 (설계 문서)

## 프로젝트 개요
실시간으로 변하는 개인 관심 데이터(게임 시세/공지, 암호화폐, 환율, 서비스 상태)를 투명하게 보여주는 개인용 대시보드.

## 기술 스택
- Next.js 16.3.3 (App Router) + React 19 + TypeScript strict
- Tailwind CSS 4
- TanStack Query 5
- Vitest + Testing Library + Playwright
- Vercel 배포

세부 근거는 `계획.md` 1단계, `Codex_작업지시서.md` 2절 참고.

## 위젯 구성 (확정)
1. 로스트아크 공지
2. 로스트아크 거래장 시세
3. Upbit 암호화폐 시세
4. 한국수출입은행 고시 환율
5. GitHub 서비스 상태

## 시스템 구조
브라우저는 `/api/widgets/*` Route Handler만 호출 → 서버가 외부 API 키를 사용해 조회 → 공통 `WidgetData<T>` 형식으로 정규화해 반환. 상세 타입·상태값·adapter 분리 방식은 `Codex_작업지시서.md` 4절 참고.

서버 계층은 공급자 adapter와 공통 HTTP·캐시 계층을 분리했다. 공통 계층이 timeout, 지수 백오프, 429 즉시 중단, 503 분기, 위젯별 TTL, 동일 요청 promise dedupe, 마지막 성공값의 stale 전환을 담당한다. Lost Ark `/markets/options` 메타데이터는 별도로 24시간 캐시한다.

거래장 위젯은 사용자가 입력한 50자 이하 아이템명을 서버에서 검증한 뒤 `/markets/options`의 유효 상위 카테고리를 순회한다. 환율 위젯은 화면의 21개 통화 목록에서 선택하며, 두 Route Handler의 캐시 키는 검색어·통화별로 분리한다. 따라서 `LOSTARK_MARKET_ITEM_NAME`, `EXIM_CURRENCY` 환경변수는 더 이상 필요하지 않다.

## 구현된 API
| Route Handler | 외부 공급자 | TTL |
|---|---|---:|
| `/api/widgets/upbit-ticker` | Upbit `KRW-BTC` | 20초 |
| `/api/widgets/status` | GitHub Status summary | 5분 |
| `/api/widgets/exchange-rate` | 한국수출입은행 신규 `oapi` | 1시간 (최대 24회/일) |
| `/api/widgets/lostark-notices` | Lost Ark notices | 15분 |
| `/api/widgets/lostark-market` | Lost Ark markets | 5분 |
