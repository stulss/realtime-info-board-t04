상세 C01–C28 판정은 [`00_과제_요구사항_매핑.md`](./00_과제_요구사항_매핑.md)에 있다.

- `[x]` C03–C18: 공개 원천, 표시 맥락, 비밀값 검색, 5종 합성 장애, stale/empty/retry
- `[x]` C20 및 C23–C28: 동일 날짜 중복 방지, 원천·저장·계산·화면 대조, 문서/AI 3줄
- `[x]` C01: 공개 배포 URL `https://realtime-info-board-t04.vercel.app/` 확인
- `[~]` C19, C21, C22: recover-d2 asset·실제 다음 KST 날짜 앱 재실행 대기

## 장애 5종

| 종류 | 합성 재현 | 화면 상태 | 정상값 보존 | 다시 시도 |
|---|---|---|---|---|
| timeout | 750ms 지연 + 300ms client timeout | 시간 초과 | stale/empty | 가능 |
| 401/403 | HTTP 401 | 인증 실패 | stale/empty | 가능 |
| 호출 제한 | HTTP 429 | 호출 제한 | stale/empty | 가능 |
| 오프라인 | offline payload/연결 실패 | 오프라인 | stale/empty | 가능 |
| 형식 변경 | 필수 필드 없는 JSON | 응답 형식 변경 | stale/empty | 가능 |

합성 응답은 실제 날짜 기록이나 원천값을 대체하지 않는다(C26).

## 실제 원천 대조 및 변화

| 날짜 | 원천/저장/계산입력/화면 | 단위 |
|---|---:|---|
| 2026-08-25 | 109,165,000 / 109,165,000 / 109,165,000 / 109,165,000 | KRW |
| 2026-08-26 | 109,830,000 / 109,830,000 / 109,830,000 / 109,830,000 | KRW |

변화는 `+665,000 KRW`, `+0.61%`이며 손계산과 일치한다. 새 실제 KST 날짜 앱 실행이 끝나기 전까지 C19/C21/C22는 보류한다.

## 증거

마지막 성공한 전체 E2E 증거는 `docs/검증스크린샷/2026-08-27T05-19-10-578Z/`다. 각 실행은 새 UTC timestamp 폴더를 만들고 기존 폴더/파일이 있으면 중단한다. 중단된 재실행 폴더도 삭제·덮어쓰지 않는다.
